## Caveats

The brochure contains screenshots, partial UI flows and some Bengali text with embedded/legacy font encoding that extracts imperfectly. Some features are implied rather than specified in rule-level detail. For example, it illustrates 75% attendance alert in medical education, but does not define jurisdiction-specific eligibility rules. This package therefore distinguishes source-referenced feature scope from proposed implementation contracts and open product decisions.

Use the page images to settle disputes and get stakeholder sign-off before making high-stakes eligibility, grade, fee or policy logic authoritative.
